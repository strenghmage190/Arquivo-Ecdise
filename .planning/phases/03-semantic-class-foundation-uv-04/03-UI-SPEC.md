## Naming Convention (LOCKED — CONTEXT D-12, D-13)

1. **Flat kebab-case with `.uv-` prefix** — follows existing file convention (`.uv-editor-header`, `.uv-tools-dock`, `.uv-right-panel`) and the 4 roadmap pilot names. BEM, prefixes without `.uv-`, and generic names are NOT allowed.
2. **Variant modifier = `--` suffix** (e.g. `.uv-channel-btn--red`, `.uv-range-slider--inline`, `.uv-flex-row--push`).
3. **Boolean state = `.is-active`** — never reuse `.active` (already claimed by `.tab.active` / `.tool-button.active`).
4. **Additive aliases only**: semantic classes (`.uv-workspace`, `.uv-sidebar`) are ADDED to load-bearing elements, never substituted for load-bearing names (`.uv-editor-panel`, `.uv-right-panel`). Load-bearing selectors keep their rules byte-identical (D-14: new rules live in a NEW appended block, sectioned "Semantic classes", with region comment headers: header / viewport-canvas / sidebar / property-group / info-box / channel-buttons / mask-controls / utilities).
