# Plan 02-02: Layer Deletion, Batch Operations & Undo Safety

**Phase:** 02-layerspanel-and-layer-operations-refactor
**Plan:** 02-02
**Status:** Ready

## Goal

Provide instant single-click layer deletion, multi-select batch deletion and grouping with reliable undo (`Ctrl+Z`) support, complete resource cleanup, and refined drag-and-drop visuals.

## Target Files

- `src/components/LayersPanel.tsx`
- `src/components/LayerItem.tsx`
- `src/components/tools/UVEditor.tsx`
- `src/components/tools/UVEditor.css`

## Tasks

### Task 1: Streamline Single-Click Deletion with Undo Safety
- In `src/components/LayerItem.tsx`:
  - Ensure the `Trash2` icon button triggers `props.onDelete(layer.id)` with 1 click without unnecessary blockage.
- In `src/components/tools/UVEditor.tsx`:
  - In `deleteLayer(id)`:
    - Revoke object URLs if image layer.
    - Clear layer drawing / cached canvases to prevent memory leaks.
    - Update `selectedLayer` to previous or next layer if available.
    - Synchronously record canvas state into `history` so `Ctrl+Z` (Undo) immediately restores the deleted layer.

### Task 2: Robust Multi-Selection & Batch Actions
- In `src/components/LayersPanel.tsx`:
  - Show persistent/dynamic batch toolbar when 1 or more layer checkboxes are checked (`groupChecks`).
  - Implement batch actions:
    - `Excluir Selecionados`: deletes all checked layers at once, frees memory, logs history.
    - `Bloquear/Desbloquear`: toggles lock state for all checked layers.
    - `Agrupar Selecionados`: creates a new group layer containing all checked layers and unchecks them.

### Task 3: Drag-and-Drop & Thumbnail Polish
- In `src/components/LayersPanel.tsx` and `UVEditor.css`:
  - Enhance `react-beautiful-dnd` drag feedback (active glow, elevation shadow, smooth drop animation).
  - Polish live thumbnail updates on `LayerItem` when drawing or transforming images.

## Verification

- Delete a layer with 1 click, press `Ctrl+Z` to undo, verify the layer is fully restored.
- Select 3 layers via checkboxes, click "Excluir Selecionados", verify all 3 are removed.
- Drag to reorder layers and verify visual order reflects canvas z-index.
- Run `npm run typecheck` to confirm zero errors.
