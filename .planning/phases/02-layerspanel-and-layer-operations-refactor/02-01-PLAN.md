# Plan 02-01: Quick Creation & Image Placement Pipeline

**Phase:** 02-layerspanel-and-layer-operations-refactor
**Plan:** 02-01
**Status:** Ready

## Goal

Provide prominent, fast-access layer creation controls (`+ Imagem`, `+ Desenho`, `+ Texto`) in `LayersPanel.tsx` and streamline automatic image file placement and scaling in `UVEditor.tsx`.

## Target Files

- `src/components/LayersPanel.tsx`
- `src/components/tools/UVEditor.tsx`
- `src/components/tools/UVEditor.css`

## Tasks

### Task 1: Prominent Image Ingestion & Fast Layer Creation
- In `src/components/LayersPanel.tsx`:
  - Add explicit `+ Imagem` (`ImageIcon`), `+ Desenho` (`Pencil`), and `+ Texto` (`Type`) buttons to the header action bar and footer.
  - Add hidden file input hook inside `LayersPanel` or trigger `props.onAddImageLayer` directly.
  - Create high-visibility empty-state card when `layers.length === 0` offering 3 quick-action cards ("Adicionar Imagem", "Criar Desenho", "Inserir Texto").

### Task 2: Automatic Centered Image Scaling in UVEditor
- In `src/components/tools/UVEditor.tsx`:
  - Refactor `addImageLayer(file: File)` / `setImageFile`:
    - Load image dimensions via `Image()` / `createObjectURL`.
    - Auto-fit into canvas bounds preserving aspect ratio (e.g. max 80% canvas width/height).
    - Center image at `(canvasWidth - w) / 2`, `(canvasHeight - h) / 2`.
    - Create layer with name derived from filename (e.g. `img_clue.png`), select it, switch tool to `'select'`, and call `pushHistory()`.

### Task 3: Header & Footer Action Bar Styling
- In `src/components/tools/UVEditor.css`:
  - Style `.layers-quick-create-bar` with neon bordered cyber buttons.
  - Style `.layers-empty-state` with subtle glowing border and quick-create action cards.

## Verification

- Click `+ Imagem`, pick an image, and verify it appears centered on the canvas, selected in the layer list, with an accurate thumbnail.
- Click `+ Desenho` and `+ Texto`, verify new layers appear instantly.
- Run `npm run typecheck` to verify no type regressions.
