## 3. Cross-Phase Integration & E2E Flows

1. **Layer Management -> Drawing Canvas:** Adding images, rasterizing, or creating drawing layers updates the stack, triggers canvas re-render, and maintains active layer selection.
2. **Tools -> Dynamic Cursor -> Canvas:** Selecting `Pencil` or `Eraser` hides OS cursor, displays `.mask-cursor` scaled to zoom and brush size, and maps clicks directly to the underlying canvas buffer.
3. **Full-Screen Portal Integration:** Opening `UVEditor` from `CreateClueModal` launches a 100vw/100vh portal with responsive letterboxing math, allowing seamless drawing on high-res images.
4. **Save & Export Pipeline:** Multi-layer composite with RGB channel filtering properly encodes into PNG export payload without data loss.
