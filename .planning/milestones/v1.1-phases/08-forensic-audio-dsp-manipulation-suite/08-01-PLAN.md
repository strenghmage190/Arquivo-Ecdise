# Phase 8: Forensic Audio DSP & Manipulation Suite

**Goal:** Implement comprehensive audio editing and forensic filtering tools.

## Decisions Captured from Context
- **Interactive Timeline:** `wavesurfer.js` (Regions plugin).
- **DSP Filters:** Native Web Audio API (`BiquadFilterNode`).
- **Synthesis UI:** Sidebar panels integrated into `AudioLab`.

## Implementation Steps

### 1. Extensão da UI do AudioLab
- Atualizar `src/components/tools/audiolab/AudioLab.tsx` para acomodar abas na lateral esquerda (Esteganografia, Filtros DSP, Gerador de Sinais).

### 2. Componentes de Controle (Filtros & Sinais)
- Criar `DSPFiltersPanel.tsx` (Controles para Highpass, Lowpass, Bandpass, Notch).
- Criar `SignalGeneratorPanel.tsx` (Gerador de Tons/Ruído Branco/Morse para criar a base sem depender de upload).

### 3. Integração do Editor na Timeline
- Adicionar o `@wavesurfer/plugin-regions` no `AudioLayerPanel.tsx`.
- Permitir ao usuário arrastar para selecionar um trecho. Capturar `start` e `end` para a renderização final.

### 4. Motor DSP (Web Audio)
- Criar `src/utils/dspAudioEngine.ts`.
- Configurar um `OfflineAudioContext`.
- Mixar camada Base + Sinal Oculto, cortar o trecho selecionado pelas Regions, e aplicar a cadeia de `BiquadFilterNode`.
- Converter o buffer resultante para Blob (`WAV`/`MP3`) finalizando o fluxo.

## Verificação
- Garantir que o sinal gerado obedeça a seleção do trim (Regions).
- Testar a audibilidade do filtro (ex: aplicar lowpass e confirmar som abafado).
