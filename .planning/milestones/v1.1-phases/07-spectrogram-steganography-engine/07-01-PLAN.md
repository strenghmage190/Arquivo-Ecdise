## Plan 07-01: `spectrogramSynthesizerWorker.ts` — Core Synthesis Engine

**Goal:** Create an enhanced Web Worker that upgrades the existing `textSynthWorker.ts` to support:
- Full `ImageData` input (any source: image upload, drawing canvas, or text render)
- Configurable duration (seconds, not pixels-per-unit)
- Configurable frequency range (Hz min/max from sliders)
- Configurable intensity/amplitude (0–1)
- Pink noise generation for fallback bed
- Progress reporting

**Files to create/modify:**
- `src/utils/spectrogramSynthesizerWorker.ts` [NEW]

**Implementation:**

```typescript
// spectrogramSynthesizerWorker.ts
// Enhanced spectrogram synthesis Web Worker
// Accepts: ImageData + synthesis params → Float32 PCM buffer (stereo or mono)

type SynthParams = {
  sampleRate: number;       // 44100 or 48000
  durationSec: number;      // total audio duration in seconds (1-60)
  minFreqHz: number;        // minimum frequency Hz (e.g. 8000)
  maxFreqHz: number;        // maximum frequency Hz (e.g. 18000)
  intensity: number;        // amplitude of steg signal (0-1)
  mixRatio: number;         // blend ratio: 0 = base audio only, 1 = steg only
  usePinkNoiseBed: boolean; // if true, generate pink noise as audio base
  baseAudioBuffer?: Float32Array | null; // float32 PCM of base audio (optional)
};

type MsgIn = {
  cmd: 'synthesize';
  width: number;
  height: number;
  imageData: ArrayBuffer; // RGBA Uint8ClampedArray bytes
  params: SynthParams;
};
```

**Algorithm:**
1. Parse ImageData RGBA → grayscale brightness matrix
2. Calculate `samplesPerColumn = floor(sampleRate * durationSec / width)`
3. For each column x, for each row y:
   - `brightness = (R+G+B)/3` normalized 0–1
   - `freqNorm = 1 - (y / (height-1))` (top = high freq)
   - `freq = minFreqHz + freqNorm * (maxFreqHz - minFreqHz)`
   - Add sine wave at `freq` with amplitude `brightness * intensity * 0.9`
   - Apply Hann windowing per column to reduce spectral smearing
4. Generate pink noise bed if `usePinkNoiseBed === true` (Voss-McCartney algorithm)
5. Mix: `output[i] = stegSignal[i] * mixRatio + baseAudio[i] * (1 - mixRatio)`
6. Normalize output to prevent clipping (max ±1.0)
7. Report progress every 16 columns via `{ cmd: 'progress', percent: N }`
8. Return `{ cmd: 'result', samples: Float32Array.buffer, sampleRate }`

**Verification:**

- Worker receives/sends correct typed messages
- Pink noise fallback produces non-silent output

**Colormap functions:**
```typescript
const colormaps = {
  cyberneon: (t: number) => [
    Math.floor(t * 0),              // R
    Math.floor(t * 243),            // G → 00f3ff cyan
    Math.floor(t * 255)             // B
  ],
  inferno: (t: number) => { /* yellow/orange/red black */ },
  viridis: (t: number) => { /* green/blue/yellow */ }
};
```

**Rendering:**

- Overlay axis labels: Y-axis (Hz min/max), X-axis (0s, durationSec/2, durationSec)
- Use `requestAnimationFrame` to avoid blocking UI thread
