# Plan 01-01: Modernize Iconography with Lucide React

**Phase:** 01-design-system-and-iconography-modernization
**Plan:** 01-01
**Status:** Ready

## Goal

Replace every emoji in `UVEditor.tsx`, `LayersPanel.tsx`, `LayerItem.tsx`, and `LayerIcons.tsx` with clean, scalable, accessible Lucide React SVG components.

## Target Files

- `src/components/tools/UVEditor.tsx`
- `src/components/LayersPanel.tsx`
- `src/components/LayerItem.tsx`
- `src/components/LayerIcons.tsx`

## Tasks

### Task 1: Refactor LayerIcons and LayerItem Iconography
- Update `src/components/LayerIcons.tsx` to export standardized Lucide icon wrappers for all layer types (`Type`, `Image`, `Pencil`, `Folder`, `FileText`, `Layers`, `Eye`, `EyeOff`, `Lock`, `Unlock`, `Copy`, `Trash2`, `Plus`, `FolderPlus`).
- Update `src/components/LayerItem.tsx`:
  - Replace `getLayerIcon` emoji strings (`'🅰️'`, `'🖼️'`, `'✏️'`, `'📁'`, `'📄'`) with corresponding Lucide SVG icons.
  - Replace visibility buttons (`'👁️'` / `'🚫'`) with `<Eye size={14} />` / `<EyeOff size={14} />`.
  - Replace lock buttons with `<Lock size={14} />` / `<Unlock size={14} />`.
  - Add accessible aria-labels and clean icon wrappers.

### Task 2: Refactor LayersPanel Action Bar Iconography
- Update `src/components/LayersPanel.tsx`:
  - Replace footer action emojis/placeholders with Lucide icons (`Plus` for add layer, `FolderPlus` for group, `Trash2` for batch delete).
  - Replace group toggle arrows (`'▾'` / `'▸'`) with `<ChevronDown size={14} />` / `<ChevronRight size={14} />`.
  - Ensure all icon buttons have tooltip text and `aria-label`.

### Task 3: Refactor UVEditor Header and Toolbar Iconography
- Update `src/components/tools/UVEditor.tsx`:
  - Header: Replace `'🔬 Editor RGB Forense'`, `'🎨 Editor de Filtros'`, `'💡 Editor UV'` with Lucide icons (`<Radio size={18} />`, `<Palette size={18} />`, `<Eye size={18} />`) beside styled header text.
  - Toolbar Dock: Replace `'🖱️'`, `'✏️'`, `'🩹'`, `'🖼️'`, `'🅰️'` with `<MousePointer size={18} />`, `<Pencil size={18} />`, `<Eraser size={18} />`, `<Image size={18} />`, `<Type size={18} />`.
  - Header buttons: Add `<Save size={16} />` to Salvar and `<X size={16} />` to Fechar.

## Verification

- Run `npm run typecheck` to confirm all Lucide icon imports and TypeScript typings are valid.
- Search for emojis across `src/components/tools/UVEditor.tsx`, `src/components/LayersPanel.tsx`, and `src/components/LayerItem.tsx` to verify 0 emojis remain.
