# Phase 3: Forensic RGB Channel Isolation

## 1. Real-Time Channel Mask in Viewport

### `src/components/tools/UVEditor.tsx`
- In the `redrawAll()` function, after completing the standard layer rendering (lines ~1020-1050), check if `mode === 'rgb'`.
- If `mode === 'rgb'`, apply a color mask over the entire canvas to visually isolate the `targetChannel` (`R`, `G`, or `B`):
  - Set `ctx.globalCompositeOperation = 'multiply'`.
  - Draw a filled rectangle over the viewport with color:
    - `'R'` -> `rgba(255, 0, 0, 1)` (Zeroes out green and blue).
    - `'G'` -> `rgba(0, 255, 0, 1)` (Zeroes out red and blue).
    - `'B'` -> `rgba(0, 0, 255, 1)` (Zeroes out red and green).
  - This provides real-time visual feedback that only the targeted channel is active.

## 2. Hard Pixel Isolation on Export

### `src/components/tools/UVEditor.tsx`
- To ensure forensic authenticity, simply multiplying visually isn't enough for the final exported file—we must hard-erase the other channels.
- In `handleSaveClick()` or before triggering `onSave(blob)`:
  - If `mode === 'rgb'`, get the `ImageData` from the canvas.
  - Iterate over the `Uint8ClampedArray` pixels.
  - If `targetChannel === 'R'`, set green (`i+1`) and blue (`i+2`) to `0`.
  - If `targetChannel === 'G'`, set red (`i`) and blue (`i+2`) to `0`.
  - If `targetChannel === 'B'`, set red (`i`) and green (`i+1`) to `0`.
  - `putImageData` back to a temporary canvas and export *that* temporary canvas to ensure the saved file is strictly single-channel.

## 3. Verify RGB Draw Target
- Ensure drawing strokes only map to the selected channel if the base background isn't doing the heavy lifting. The `ImageData` sweep on export guarantees the forensic output is perfect, but real-time preview (multiply) makes the UX seamless.
