# Requirements: Arquivo Ecdise — v2.0 Terminal Ordo Realitas

**Defined:** 2026-09-07
**Core Value:** Um sistema forense imersivo onde o chrome é invisível (monocromático) e a única cor que o jogador vê vem dos dados do caso — tornando cada Elemento sobrenatural instantaneamente legível e cinematográfico.

## v2.0 Requirements

### Design System

- [x] **DSYS-01**: Sistema define paleta monocromática do chrome (--bg, --surface, --border, --text-primary, --text-secondary) como CSS custom properties
- [x] **DSYS-02**: Vermelho institucional (#8B1414) usado exclusivamente para ações destrutivas (sair, excluir, tag CONFIDENCIAL)
- [x] **DSYS-03**: Tokens de Elementos (--el-sangue, --el-morte, --el-energia, --el-conhecimento) definidos para uso nos dados de caso
- [x] **DSYS-04**: Tokens de Evoluções (--ev-metamorfose, --ev-encarnacao, --ev-apoteose, --ev-sintese, --ev-quimera, --ev-singularidade) com gradientes duais
- [x] **DSYS-05**: border-radius: 0 global como padrão (exceto toolbar flutuante)
- [x] **DSYS-06**: Proibições aplicadas: sem glassmorphism, sem box-shadow colorido, sem drop-shadow neon

### Tipografia

- [x] **TYPO-01**: Cinzel (600/800) para títulos de caso e headings principais
- [x] **TYPO-02**: Share Tech Mono para IDs, dados, Membrana, status e metadados
- [x] **TYPO-03**: Special Elite para descrições de evidências e documentos narrativos
- [x] **TYPO-04**: Teko para carimbos de ameaça e alertas (CONFIDENCIAL, GRAU III)
- [x] **TYPO-05**: Google Fonts importado com font-display: swap, max 4 famílias

### Header

- [x] **HEAD-01**: Brasão da Ordem + texto "ARQUIVOS // DIVISÃO FORENSE" como identidade do header

### Cards de Caso

- [x] **CARD-01**: Selo elemental (badge no canto com cor do Elemento atribuído)
- [x] **CARD-02**: Código de dossiê monoespaçado (Share Tech Mono, ID: #XXX-NN)
- [x] **CARD-03**: Miniatura da evidência principal com hover zoom
- [x] **CARD-04**: Metadados paranormais (classificação de ameaça, contagem de evidências)
- [x] **CARD-05**: Borda temática 1px com cor sutil do Elemento do caso
- [x] **CARD-06**: Data em fonte carimbo (Special Elite) na base
- [x] **CARD-07**: Efeito hover por Elemento (Energia=raios, Sangue=sangramento, Conhecimento=sigilos, Morte=lodo)
- [x] **CARD-08**: Clicar no card abre o dossiê diretamente (sem botão separado obrigatório)

### Criação de Caso

- [x] **CREA-01**: Card "+ INICIAR PROTOCOLO" com borda tracejada e sigilo translúcido, hover acende dourado
- [x] **CREA-02**: Mestre seleciona Elemento do caso na criação
- [x] **CREA-03**: Mestre pode atribuir Evolução ao caso (opcional, revelável pelo mestre)

### Toolbar

- [x] **TOOL-01**: Cápsula única (rounded-full, bg surface, border 1px)
- [x] **TOOL-02**: Todos os emojis substituídos por Lucide React icons
- [x] **TOOL-03**: Hover clarea borda levemente, nunca muda matiz
- [x] **TOOL-04**: Zero fundos coloridos individuais nos botões

### Formulários

- [x] **FORM-01**: Checkboxes customizados com padrão do sistema (surface/border)
- [x] **FORM-02**: Selects customizados
- [x] **FORM-03**: Inputs com foco vermelho institucional (contorno fino, sem glow)
- [x] **FORM-04**: Textareas padronizados

### Rodapé

- [x] **FOOT-01**: Ticker monoespaçado (Share Tech Mono) com animação horizontal e mensagens do sistema

### Cards de Evidência
