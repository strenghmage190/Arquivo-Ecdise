# Milestone Archive: v1.0 Requirements

**Shipped:** 2026-08-15
**Status:** Completed (14/14 satisfied)

---

## 1. Iconography & Visual Modernization (ICON)
- [x] **ICON-01:** Replace all emojis in `UVEditor.tsx` toolbar (`select`, `draw`, `erase`, `placeImage`, `placeText`) with Lucide React icons (`MousePointer`, `Pencil`, `Eraser`, `Image`, `Type`).
- [x] **ICON-02:** Replace all emojis in header, channel selectors (`R`, `G`, `B`), and mode indicators with Lucide icons (`Sparkles`, `Radio`, `Layers`, `Eye`, `Palette`, `Check`).
- [x] **ICON-03:** Replace all emojis in `LayerItem.tsx` (type indicators, visibility toggle, lock toggle, delete, duplicate, mask icons) with Lucide icons.
- [x] **ICON-04:** Ensure all icons adhere to the Cyberpunk/Nexus neon accent design tokens defined in `src/styles/nexus.css`.

## 2. Layer Management & Image Ingestion (LAYR)
- [x] **LAYR-01:** Redesign `LayersPanel` header and action bars with intuitive buttons for "Nova Camada de Desenho", "Adicionar Imagem", "Adicionar Texto", "Criar Grupo" and "Limpar Tudo / Excluir".
- [x] **LAYR-02:** Provide seamless image ingestion allowing users to pick an image, see an inline scaled preview, position it on the canvas, and automatically register it as a named image layer.
- [x] **LAYR-03:** Streamline individual layer deletion and multi-select batch deletion with clear confirmation and undo/history push.
- [x] **LAYR-04:** Improve visual feedback for layer drag-and-drop reordering, active layer selection highlight, locked status, and mask editing state.

## 3. Canvas Mouse Tracking & Interaction (CURS)
- [x] **CURS-01:** Ensure accurate and visible mouse cursor styling across all active tools (`crosshair` for draw, `cell`/custom ring for eraser/mask, `move` for dragging layers, `text` for inline text editor).
- [x] **CURS-02:** Implement a visible brush-size indicator / cursor circle following the pointer during brush and eraser operations on the canvas.
- [x] **CURS-03:** Fix cursor rendering and selection bounds when hovering over cipher/code text overlays and transform bounding boxes.

## 4. Modularization & Architecture (MODU)
- [x] **MODU-01:** Extract `UVToolbar`, `UVViewport`, `UVColorPalette`, `UVPropertiesPanel`, and `UVMaskControls` into standalone subcomponents under `src/components/tools/uveditor/`.
- [x] **MODU-02:** Extract stateful canvas drawing and history management logic into dedicated custom hooks (e.g., `useUVCanvasState`, `useUVHistory`).
- [x] **MODU-03:** Eliminate raw inline styles from `UVEditor.tsx` and migrate all layout and visual properties to `UVEditor.css` / scoped CSS classes.

## Non-Functional Requirements
- [x] **NFR-PERF:** Canvas redrawing and layer transformations maintain 60fps.
- [x] **NFR-A11Y:** Interactive buttons have descriptive labels and tooltips.
- [x] **NFR-COMPAT:** Backward compatibility with existing saved canvas states, mask channels, and Supabase image export payloads.
