# 📁 Arquivo Ecdise (Terminal Ordo Realitas)

Bem-vindo ao **Arquivo Ecdise**, o terminal de investigação e banco de dados central utilizado pela Ordo Realitas. Este sistema foi desenvolvido para agentes em campo e analistas forenses organizarem e desvendarem os casos mais complexos envolvendo o paranormal.

Operando sob uma interface monocromática de terminal seguro, o sistema oferece um arsenal completo de ferramentas para extrair a verdade daquilo que tenta se manter oculto nas sombras.

---

## 🕵️‍♂️ O que é este sistema?

O **Arquivo Ecdise** é uma plataforma imersiva de RPG e ARG (Alternate Reality Game) para o universo de Ordem Paranormal. Ele não é apenas um site; é a representação virtual do sistema operacional dos investigadores. 

Aqui, os jogadores/agentes podem acessar casos abertos, inspecionar evidências detalhadamente e usar ferramentas forenses simuladas para resolver enigmas criados pelo Mestre (ou pela própria Ordem). Tudo isso em um ambiente colaborativo e altamente interativo.

---

## 🛠️ Arsenal Forense (Módulos e Ferramentas)

O terminal é equipado com uma vasta gama de módulos de análise interativos, separados por especialidade:

### 🎙️ Laboratório de Áudio (Audio Lab)
Ferramentas avançadas para processamento de sinais e extração de anomalias sonoras:
*   **Espectrogramas (Pro & Real-Time):** Renderização visual de áudio para descobrir mensagens em esteganografia (imagens escondidas no som).
*   **Audio Mixer & Isolador de Canais:** Separação de frequências e canais para isolar vozes ou remover ruídos paranormais de fundo.
*   **Audio Decrypter & Forge:** Manipulação de pitch e velocidade para descriptografar áudios distorcidos ou invertidos.
*   **Signal Reconstructor:** Reconstrução de sinais de áudio corrompidos.

### 🔬 Análise de Imagem e Espectros (Forensic Imaging)
Filtros e editores para encontrar detalhes invisíveis a olho nu:
*   **Editor UV (Ultravioleta):** Revela tintas invisíveis, sangue ou mensagens escondidas nas camadas secretas de uma evidência.
*   **Editor Termal (Thermal):** Análise de assinaturas de calor em imagens.
*   **Forensic Channel Editor:** Manipulação precisa de canais de cor (RGB) e exposição para revelar figuras ocultas na escuridão.
*   **Glitch Engine & Glitch Solver:** Análise de imagens digitais corrompidas, permitindo "desbugar" a imagem para ver o que há por trás.
*   **Lente Decifradora (Decipher Lens):** Lente de inspeção local (lupa especial) para varrer documentos.

### 🔐 Criptografia e Decodificação
Sistemas para quebrar bloqueios e traduzir mensagens ocultas:
*   **Máquina Enigma (Enigma Machine):** Cifragem e decifragem de mensagens baseada em rotores.
*   **Decodificador Universal & Manual:** Ferramentas para quebrar cifras de substituição, binário, base64, etc.
*   **Visualizador Hexadecimal (Hex Viewer):** Inspeção de arquivos corrompidos direto no nível do código.
*   **Simuladores de Bloqueio:** Pattern Lock (desenho padrão de celular) e Numeric Keypad.

### 🧩 Simulações e Recuperação de Evidências
*   **CCTV Player:** Interface para análise quadro a quadro de fitas e câmeras de segurança.
*   **Visualizador de Celular (Phone Viewer):** Interface emulada para acessar mensagens e arquivos dentro do celular de um suspeito.
*   **Shredder Puzzle:** Minigame para reagrupar e colar documentos triturados fisicamente.
*   **Hacking Terminal & System Terminal:** Terminais de linha de comando para invadir sistemas restritos do caso ou rodar scripts de extração.

## 📂 Gestão de Casos (O Hub)

Além das ferramentas, o Arquivo Ecdise atua como o cérebro da investigação:
*   **Quadro de Investigação:** Um mural interativo (estilo "fios vermelhos") para organizar espacialmente todas as pistas e visualizar conexões.
*   **Criação de Pistas (Creator Hub):** Interface para Mestres e Agentes subirem novas evidências, definindo metadados, camadas secretas e configurando os puzzles (ex: exigindo senha para abrir um arquivo).
*   **Inspeção Profunda (Inspection Modal):** Visualização em tela cheia das evidências para que a equipe possa debater cada detalhe encontrado.
