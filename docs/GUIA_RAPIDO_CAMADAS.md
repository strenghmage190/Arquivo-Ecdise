# 🎨 Guia Rápido - Sistema de Camadas do UVEditor

## Início Rápido

### 1️⃣ Criar sua Primeira Camada

**Opção A: Adicionar Texto**
1. Clique no botão **➕** no painel de camadas
2. Uma nova camada de texto aparece no centro do canvas
3. Clique duplo no nome para personalizá-la

**Opção B: Adicionar Imagem**
1. Clique em **🖼️ Imagem** nas ferramentas
2. Selecione uma imagem do seu computador
3. Ajuste a escala
4. Clique no canvas para posicionar

**Opção C: Desenhar Diretamente**
1. Escolha uma cor
2. Ajuste o tamanho do pincel
3. Desenhe no canvas
4. Isso cria marcas permanentes (não são camadas editáveis)

---

## 🎯 Operações Básicas

### Selecionar uma Camada
- **Clique** na camada no painel lateral
- OU clique no elemento visual no canvas
- A camada ativa fica destacada em roxo

### Renomear
1. **Clique duplo** no nome da camada
2. Digite o novo nome
3. Pressione **Enter** para confirmar

### Mover uma Camada
1. Selecione a camada
2. **Arraste** no canvas para reposicionar
3. O elemento se move em tempo real

### Ajustar Opacidade
1. Selecione a camada
2. Use o **slider de Opacidade** que aparece embaixo
3. Varie de 0% (transparente) a 100% (opaco)

---

## 🔄 Organização e Ordenação

### Reordenar (Empilhamento)
- **Arraste e solte** camadas no painel
- Camadas no **topo da lista** = mais na frente
- Camadas no **fundo da lista** = mais atrás

💡 **Dica**: Use a ordenação para controlar o que aparece "em cima" e "embaixo"

### Ocultar Temporariamente
1. Clique no ícone **👁️** da camada
2. Ela desaparece do canvas (mas não é excluída)
3. Clique novamente para mostrar

🎯 **Útil para**: Focar em outras partes sem deletar

### Bloquear (Proteger)
1. Clique no ícone **🔓** da camada
2. Muda para **🔒** (bloqueada)
3. Agora ela não pode ser editada acidentalmente
4. Clique novamente para desbloquear

🔒 **Use para**: Proteger elementos já finalizados

---

## ⚡ Operações Avançadas

### Duplicar (Fazer Cópia)
1. Selecione a camada desejada
2. Clique no botão **📑** na linha da camada
3. Uma cópia aparece logo acima, levemente deslocada
4. Nome: "Nome Original (cópia)"

💎 **Perfeito para**: Experimentar edições sem perder o original

### Mesclar para Baixo
1. Selecione a camada que quer combinar
2. Clique no botão **⬇️**
3. Ela se funde com a camada imediatamente abaixo
4. As duas viram uma só

⚠️ **Atenção**: Esta operação não pode ser desfeita

### Mesclar Todas Visíveis
1. Clique no botão **🔗** no cabeçalho do painel
2. TODAS as camadas visíveis se combinam em uma
3. Camadas ocultas são mantidas separadas
4. Nome: "Camadas Mescladas"

🎁 **Ideal para**: Finalizar o trabalho e reduzir complexidade

## 🚀 Fluxo de Trabalho Recomendado

### Para Edição Criativa
```
1. Adicione vários elementos como camadas separadas
2. Organize com nomes descritivos
3. Ajuste opacidades para efeitos de transparência
4. Reordene até obter a composição desejada
5. Oculte/mostre elementos para comparar opções
```

### Para Experimentação
```
1. Crie sua arte base
2. DUPLIQUE camadas importantes
3. Experimente na cópia
4. Se gostar: delete o original
5. Se não gostar: delete a cópia
```

### Para Finalização
```
1. Revise todas as camadas
2. Delete as que não estão sendo usadas
3. Bloqueie elementos finalizados
4. Mescle grupos relacionados
5. Por fim: Mescle Visíveis para exportação
```

## 💡 Dicas Profissionais

### 🎨 Organização
- **Nomeie tudo**: "Cabelo", "Fundo", "Efeitos UV", etc.
- **Agrupe visualmente**: Mantenha camadas relacionadas próximas na lista
- **Limite de camadas**: Tente não ter mais de 10-15 simultâneas para performance

### 🔒 Segurança
- **Bloqueie o que está pronto**: Evita edições acidentais
- **Duplique antes de arriscar**: Sempre mantenha um backup
- **Salve frequentemente**: Use o botão "✓ Confirmar" regularmente

### ⚡ Performance
- **Mescle quando possível**: Menos camadas = renderização mais rápida
- **Oculte o que não está usando**: Melhora a visualização
- **Delete o desnecessário**: Limpe camadas de teste

### 🎯 Composição
- **Camadas de ajuste**: Use opacidade baixa para efeitos sutis
- **Sobreposições**: Camadas semi-transparentes criam profundidade
- **Contraste**: Alterne entre camadas claras e escuras

## 🐛 Solução de Problemas

### "Não consigo editar minha camada"
➜ Verifique se ela não está **bloqueada** (🔒)

### "Não vejo minha camada no canvas"
➜ Verifique se ela está **visível** (👁️ ativo, não 🚫)

### "Não consigo mover uma camada"
➜ Camadas bloqueadas não podem ser movidas. Desbloqueie primeiro.

### "Perdi minha camada original"
➜ Use **Duplicar** ANTES de fazer edições arriscadas

### "O programa está lento"
➜ Tente **mesclar** algumas camadas para reduzir a quantidade total
