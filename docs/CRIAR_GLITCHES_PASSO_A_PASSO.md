# 🎨 Como Criar Glitches - Guia Passo a Passo

## 📍 Onde Criar?

No **CreateClueModal** (ao criar uma nova pista), você encontrará a seção:

```
⚡ GLITCH MAKER (Game Master)
"Use esta ferramenta para criar imagens com efeitos de glitch..."
[⚡ ABRIR GLITCH MAKER]
```

---

## 🎯 Fluxo Completo: Game Master

### 1️⃣ **Criar Nova Pista**
```
No quadro de investigação → [+ NOVA PISTA]
```

### 2️⃣ **Preencher Dados Básicos**
```
TÍTULO: "Fotografia Corrompida - Lab-047"
DESCRIÇÃO PÚBLICA: "Uma fotografia antiga parece corrompida"
TAGS: #glitch #corrupto #mistério
```

### 3️⃣ **Abrir Glitch Maker**

Na seção **"⚡ GLITCH MAKER (Game Master)"**:

```
[⚡ ABRIR GLITCH MAKER]
```

Aparece uma janela:

```
┌──────────────────────────────────────────┐

│                                          │
│ Intensidade do Deslocamento: 20%         │
│ ━━━━━━━━━━━━━━━━━━━━━ ●                  │
│                                          │
│ Corrupção Cromática: 10%                 │
│ ━━━━━━━━━━━━━━━━━━━━━ ●                  │
```

### 4️⃣ **Carregar Imagem Base**

Clique em **[Carregar Amostra]**:
- Selecione uma imagem do seu computador
- Pode ser: foto, diagrama, código, documento, etc.
- Clique em **[Carregar]** para visualizar

### 5️⃣ **Ajustar Parâmetros de Glitch**

Customize o efeito com 3 sliders:

#### A. **Frequência de Fatias** (1-50)
```
Baixo (1-10):    Poucos "cortes" na imagem
Médio (15-25):   Glitch moderado
Alto (35-50):    Muito fragmentado
```
**Exemplo**: 17 = bom glitch visível mas legível

#### B. **Intensidade do Deslocamento** (0-100%)
```
Baixo (0-20%):   Deslocamento sutil
Médio (25-50%):  Deslocamento notável
Alto (60-100%):  Fragmentação extrema
```
**Exemplo**: 33% = efeito bem visível

#### C. **Corrupção Cromática** (0-100%)
```
Baixo (0-5%):    Cores quase normais
Médio (10-30%):  Inversão RGB notável
Alto (40-100%):  Cores muito distorcidas
```
**Exemplo**: 12% = alguns pixels com cores trocadas

### 6️⃣ **Pré-visualizar**

Clique em **[Executar Análise]** para ver o efeito:
- A imagem será processada com os parâmetros
- Você pode clicar várias vezes para experimentar valores diferentes

### 7️⃣ **Salvar a Imagem Corrompida**

Quando ficar satisfeito, clique em **[Extrair Artefato]**:
- A imagem é salva automaticamente
- Volta ao modal de criar pista
- A imagem aparece como preview

### 8️⃣ **Finalizar a Pista**

De volta no CreateClueModal:
- Imagem corrompida está pronta
- Preencha outros campos se necessário
- Clique em **[SALVAR PISTA]**

## 💡 Exemplos de Configurações

### Cenário 1: Glitch Sutil (para pistas óbvias)
```
Frequência:    8
Deslocamento: 15%
Cromática:     5%
```
Resultado: Imagem pouco corrompida, quase legível

### Cenário 2: Glitch Moderado (para pistas importantes)
```
Frequência:   17
Deslocamento: 33%
Cromática:   12%
```
Resultado: Bem corrompida, mas com paciência dá para descodificar

### Cenário 3: Glitch Extremo (para mistérios)
```
Frequência:   40
Deslocamento: 70%
Cromática:    50%
```
Resultado: Muito corrompida, requer os parâmetros EXATOS

## 🔐 Criando Enigmas com Glitch

### Estrutura Sugerida:

**Pista 1: Imagem Corrompida**
```
TÍTULO: "Arquivo Recuperado #047"
DESCRIÇÃO: "Uma imagem foi recuperada, mas está muito corrompida."
IMAGEM: [foto glitchada com configuração 17-33-12]
```

**Pista 2: Dica sobre Parâmetros (Email ou Documento)**
```
TÍTULO: "Log de Laboratório"
DESCRIÇÃO: 
"Amostra 17 processada
Frequência de análise: 33%
Índice técnico: 12"
```

**Pista 3: Instruções (Se quiser ser direto)**
```
TÍTULO: "Manual do Decodificador"
DESCRIÇÃO:
"Para recuperar a imagem #047, use:
- Frequência: 17
- Intensidade: 33%
- Cromática: 12%"
```

**Resultado para o Jogador:**
1. ✓ Encontra pista com imagem corrompida
2. ✓ Desbloqueia Decodificador (DELTA-1977)
3. ✓ Encontra dicas sobre os parâmetros (17-33-12)
4. ✓ Carrega imagem no Decodificador
5. ✓ Ajusta parâmetros
6. ✓ **Clica "Executar Análise"**
7. ✓ **IMAGEM SE REVELA!**

## 🎬 Workflow Recomendado

```
1. Pense em um enigma
   ↓
2. Crie a imagem "reveladora" (um QR code, mensagem, símbolo)
   ↓
3. Abra o Glitch Maker no CreateClueModal
   ↓
4. Carregue a imagem
   ↓
5. Escolha uma configuração (ex: 17-33-12)
   ↓
6. Clique "Executar Análise"
   ↓
7. Salve com "Extrair Artefato"
   ↓
8. Crie pistas que levem aos parâmetros
   ↓
9. Salve a pista
   ↓
10. Jogadores descobrirão!
```

## ⚠️ Dicas Importantes

### Para Game Masters:

1. **Teste antes** - Sempre verifique se os parâmetros funcionam
2. **Anote os valores** - Salve: Frequência, Deslocamento, Cromática
3. **Crie boas pistas** - As dicas devem ser encontráveis
4. **Use narrativa** - Explique POR QUE a imagem está corrompida
5. **Varie** - Não use os mesmos valores sempre

## ❓ Dúvidas Comuns

**P: Posso usar a mesma imagem com glitches diferentes?**  
R: Sim! Crie múltiplas pistas, cada uma com parâmetros diferentes.

**P: Qual é o melhor tamanho de imagem?**  
R: Recomendo 800x600 ou menor. O Glitch Maker redimensiona automaticamente.

**P: Os parâmetros são aleatórios?**  
R: NÃO! Você controla 100%. Escolha os valores que quer.

**P: Posso salvar sem executar?**  
R: Recomendo executar pelo menos uma vez para ver o resultado.

**P: E se eu errar os parâmetros?**  
R: Pode abrir o Glitch Maker denovo e ajustar. Basta clicar novamente em [⚡ ABRIR GLITCH MAKER]
